## 1. Architectural finding

Collider reconstruction and cosmological large-scale-structure analysis provide two domain examples in which pairwise graphs or two-point summaries can omit higher-order or multiscale information.

The project-level conclusion is not that every domain must use a hypergraph or that pairwise methods are obsolete. It is that the evidence substrate must support:
- ordinary binary relations;
- relations over arbitrary participant sets (hyperedges);
- topological features measured across an explicitly defined filtration;
- provenance that distinguishes observation, reconstruction, prediction, simulation, and validation.

A function or relation enters the graph from source evidence or a documented specification. It is not gated by loop closure, replication, fitness, or persistence.

## 2. Hyperedge record

A hyperedge is a relation whose participant set may contain more than two entities. It must not be flattened into independent pairwise edges unless the source explicitly defines that decomposition as lossless for the intended operation.

```json
{
  "hyperedge_id": "h:...",
  "participants": ["particle:...", "particle:...", "particle:..."],
  "relationship": "parent_particle_assignment",
  "context": {
    "event_id": "event:...",
    "process": "...",
    "dataset_id": "dataset:..."
  },
  "correlation_order": 3,
  "evidence": ["evidence:..."]
}
```

The relationship label and context are domain-specific. Collider examples may use jets, leptons, parent-particle assignments, and hard-scatter context. Other domains may represent chemical reactions, multi-agent exchanges, material transformations, or ecological interactions.

## 3. Persistent-topology observation

Persistent homology records topological features across a filtration. The filtration parameter, units, range, construction method, and algorithm version are part of the observation's meaning and must be retained.

```json
{
  "topology_id": "topology:...",
  "source_id": "catalog:...",
  "method": "persistent_homology",
  "filtration": {
    "type": "...",
    "parameter": "...",
    "units": "...",
    "range": ["...", "..."]
  },
  "features": [
    {
      "homology_dimension": 2,
      "birth": "...",
      "death": "...",
      "persistence": "...",
      "feature_type": "void"
    }
  ],
  "algorithm": "...",
  "algorithm_version": "...",
  "evidence": ["evidence:..."]
}
```

Betti curves, persistence diagrams, persistence landscapes, and persistence strips are possible derived representations. They are not interchangeable; store which representation was computed and how.

A void or low-density region can carry a topological signature. It is not automatically an empty/null record.

## 4. Evidence classes

Keep these as distinct evidence records or typed evidence assertions:
- `observed`: detector, survey, or instrument measurements;
- `reconstructed`: inferred assignments or derived structures from observations;
- `predicted`: model-generated values or classifications;
- `simulated`: outputs generated by a specified simulation;
- `validated`: a result compared against an identified experimental or observational reference.

A prediction is recordable before confirmation. A simulated structure is not silently relabeled as observed. Validation points to the comparison data, method, and conditions.
