# Capability Registry

This package is the repository location for capability records and historical assessment data.

The current human-readable and machine-readable conversation-recovered registries are maintained at:

- [Prototype and requisite-skill atlas](../../docs/skills/CONVERSATION_RECOVERED_SKILL_ATLAS.md)
- [Requisite-skill registry](../../docs/skills/requisite-skills.registry.yaml)

Conversation-derived prototype descriptions are valid recovery sources. Source code is additional evidence, not a prerequisite for registering a prototype or decomposing its skills.

Capability records should preserve source thread, module, requisite skills, repository ownership, interfaces, dependencies, and evidence state. Do not infer implementation or deployment from a conversation description.

The coordinate core's available-avenue model is separate from capability cataloging. This registry describes what modules and skills exist in the recovered project corpus; it does not rank or select coordinate avenues.
